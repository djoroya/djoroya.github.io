Privacy Policy

BBVA Personal Python is a non-commercial application intended solely for its owner's personal financial analysis. It is not a publicly available banking service.

Data accessed

With the account holder's explicit consent, the application may access account identifiers, account balances and transaction information through the Enable Banking account-information API. It does not request access to initiate payments.

Purpose and legal basis

The sole purpose is to display and analyse the owner's personal account information, relying on the account holder's consent for bank access. Any permission granted through the bank's authorization process can be withdrawn through the relevant banking or provider controls.

Storage and sharing

The public pages hosted on GitHub Pages do not collect, transmit or display bank account data. The planned Python integration is intended to process data privately on the owner's controlled systems. Bank account information is not intended to be made public or sold to third parties. Enable Banking and the connected bank process information according to their own applicable notices and agreements.

Security and retention

The integration is designed to use read-only account-information access, protect API credentials and restrict access to local records. Data stored locally may be retained for personal analysis until deleted by the account owner. These statements describe the intended personal use and do not claim that an unfinished integration is already deployed.

Contact

For questions concerning this application, contact the owner using the data-protection contact email provided in the Enable Banking application registration, or via the GitHub profile.

Third-party services

This information page is hosted on GitHub Pages. See GitHub's privacy statement. Bank connection services, if activated, are supplied by Enable Banking.
